# 华数杯 A 题论文图表生产线（临时，赛后删除）

用户角色：论文手。触发场景：编程手/建模手交付新结果数据，需要出图、填表、更新论文；或论文数值需要批量对齐。

## 项目锚点（先读这些再动手）

- 工作目录：`~/Desktop/华数杯/模拟赛题目/A题：园区微电网风光储协调优化配置/`
- 论文：`A题_论文框架_v1.docx`（黄色高亮 = 待补占位，灰字 = 写作提示定稿前删；图表编号以此文件为准，新增图表先查现有编号再排）
- 风格基准：`plot_correlation.py`（字体/配色/dpi 全部沿用，不要另起风格）
- 框架生成：`build_paper_skeleton.py`（内含 docx 字体/表格/图片助手函数，直接复用）
- 相关性正确值（论文口径）：A 园区 r=0.841（p<0.001）｜B 园区 r=-0.039（n.s.）｜C 园区 r=0.560（p<0.01）

## 硬性规则（踩过的坑，别再犯）

1. Python 一律写死 `/usr/bin/python3`，不要用 `which python3` 的结果（Homebrew 路径幻影）。
2. **Excel 先数表头行再读数**：附件 1 是 1 行表头，附件 2 是 3 行表头（说明+两级表头）。合并多来源数据后，抽查首末两行与原始附件对齐——旧《风光负荷相关性汇总结果(1).xlsx》就是这里错位 1 小时，已作废，改用 `_修正版.xlsx`。
3. 禁止静默覆盖他人文件；自己生成的图/脚本可覆盖，但要在回复里明示。
4. 论文数值一律以编程手最终代码输出为准；改了正文数字必须同步摘要。
5. 中文正文标点全角，行内分隔用「｜」。

## 出图规范

- 300 dpi PNG，存 `figures/`，命名 `fig<N>_<内容>.png`，N 与论文图号一致。
- 字体 Hiragino Sans GB（`axes.unicode_minus=False`）；配色：光伏 `#F5A623`｜风电 `#2E86DE`｜风光合计 `#6C3FA0`｜负荷 `#333333`（虚线）｜强调 `#D62728`。
- 一图一结论：图题或面板标题直接带关键数值（如 r 值、成本降幅）；5 秒能读懂。

## 论文 docx 更新方法

python-docx 操作，只动占位、不动其他内容：
1. 遍历段落找含「待补」且带黄色高亮的 run，按图号/表号定位。
2. 插图：段落居中，`run.add_picture(path, width=Cm(w))`，正文图宽 13.5-15.5 cm；图题 `图 N  说明`（宋体 10.5 加粗，两空格分隔）。
3. 填表：定位到目标表格（按表题顺序），`cell.paragraphs[0]` 写入，宋体 10.5 居中，保留表头加粗。
4. 中文字体必须同时设 `run.font.name`（西文 Times New Roman）和 `rPr.rFonts` 的 `w:eastAsia`（宋体/黑体）。
